# Redacción académica

## 1. Declarar el marco antes de redactar

Antes de comenzar cualquier redacción académica, indicar brevemente:

* **Norma de citación:** utilizar la indicada por el usuario. Si no la especifica, preguntar cuál exige su curso o institución. No asumir APA automáticamente.
* **Idioma del texto:** utilizar el idioma solicitado por el usuario.
* **Idioma de las fuentes:** indicar si se utilizarán únicamente fuentes en español o también fuentes académicas en inglés u otros idiomas.
* **Origen de las fuentes:** indicar si se trabajará con fuentes proporcionadas por el usuario o si serán buscadas y verificadas mediante fuentes externas.

Después de esta declaración, proceder con la redacción.

## 2. Regla absoluta: no inventar información bibliográfica

Está estrictamente prohibido inventar:

* autores;
* títulos;
* años de publicación;
* editoriales;
* revistas;
* volúmenes o números;
* páginas;
* DOI;
* URL;
* instituciones;
* datos estadísticos;
* resultados de investigaciones;
* citas textuales;
* referencias bibliográficas.

Una referencia solo puede incorporarse si:

1. fue proporcionada por el usuario, o
2. fue localizada mediante una búsqueda real y puede verificarse.

No crear referencias únicamente porque "parecen académicas".

Si una afirmación necesita respaldo y no existe una fuente comprobada, buscar una fuente adecuada antes de citarla. Si no se encuentra, reformular la afirmación o indicar que requiere una fuente adicional.

## 3. Verificación de las fuentes

Cuando las fuentes sean buscadas externamente:

* comprobar que la fuente existe;
* verificar autor o institución responsable;
* comprobar el año de publicación;
* comprobar el título;
* verificar que el contenido realmente respalde la afirmación realizada;
* utilizar el DOI o URL únicamente cuando haya sido comprobado;
* evitar citar una fuente solo porque contiene palabras clave similares;
* no utilizar una fuente para respaldar una afirmación que la fuente realmente no demuestra.

La existencia de una fuente no significa que sea adecuada. La **pertinencia del contenido** es obligatoria.

## 4. Antigüedad de la bibliografía

Como regla general, utilizar fuentes publicadas durante los **últimos 5 años** respecto del año actual.

Si el usuario establece un período diferente, respetarlo.

Se permite utilizar una fuente anterior a ese período únicamente cuando sea una fuente:

* fundacional;
* normativa;
* clásica;
* histórica;
* teórica;
* o indispensable para explicar el origen de un concepto.

Cuando se utilice una fuente antigua por una de estas razones, indicarlo brevemente.

No utilizar fuentes antiguas simplemente porque son fáciles de encontrar.

## 5. Pertinencia de cada cita

Cada cita debe justificar específicamente la afirmación a la que acompaña.

No agregar citas:

* de relleno;
* únicamente para aumentar el número de referencias;
* porque una fuente "parece relacionada";
* al final de un párrafo completo cuando la fuente solo respalda una oración;
* para aparentar mayor nivel académico.

Si un párrafo contiene varias ideas provenientes de fuentes diferentes, distribuir las citas según corresponda.

Ejemplo:

> La computación en la nube permite acceder a recursos informáticos bajo demanda (Autor, 2024). Además, su adopción puede reducir determinados costos asociados con la infraestructura física (Autor, 2023).

No colocar ambas referencias juntas al final si cada una respalda una afirmación diferente.

## 6. Ubicación y forma de las citas

Distinguir entre:

### Cita narrativa

Utilizar cuando el autor forma parte de la oración:

> Según García (2023), la adopción de determinadas tecnologías modifica los procesos organizacionales.

### Cita parentética

Utilizar cuando el énfasis está en la información:

> La adopción tecnológica puede modificar los procesos organizacionales (García, 2023).

### Formas según cantidad de autores (verificado contra APA 7)

* **Un autor:** nombrarlo en cada cita (García, 2023).
* **Dos autores:** nombrar a ambos siempre. En paréntesis con "&" (García & López, 2023); en narrativa con "y" / "and" (García y López, 2023).
* **Tres o más autores:** primer autor + "et al." **desde la primera cita** (García et al., 2023).
* **Sin autor:** usar el título abreviado en el lugar del autor.
* **Sin fecha:** "s.f." (español) o "n.d." (inglés).
* **Cita textual corta** (menos de 40 palabras en APA): entre comillas, dentro del párrafo, con página.
* **Cita textual en bloque** (40 palabras o más en APA): párrafo aparte, con sangría, sin comillas. Preferir la paráfrasis salvo que el texto exacto sea imprescindible.

> Lo anterior es la regla APA 7. La ubicación exacta, puntuación, uso de "&"/"y", corchetes y numeración debe ajustarse a la norma solicitada (IEEE usa corchetes numerados, Vancouver numeración, ISO 690 su propio formato). Ante duda sobre una norma concreta, verificar su formato oficial antes de aplicarlo.

## 7. Citas textuales

No presentar como cita textual una frase que no haya sido comprobada directamente en la fuente.

No inventar páginas.

Si la norma exige página o localizador para una cita textual y no puede verificarse, no fabricar el dato.

Preferir la **paráfrasis académica correctamente atribuida** cuando sea suficiente para desarrollar la idea.

## 8. Lenguaje humano y académico

El texto debe sonar como un trabajo universitario redactado por una persona, manteniendo formalidad académica sin utilizar expresiones artificiales o excesivamente ornamentadas.

Evitar expresiones repetitivas o características de textos generados automáticamente, como:

* "en el vertiginoso mundo actual";
* "en la era digital actual";
* "cabe destacar que";
* "es importante señalar que";
* "juega un papel fundamental";
* "juega un papel crucial";
* "sin lugar a dudas";
* "en conclusión, podemos afirmar que";
* "en este contexto, resulta fundamental";
* "como se ha podido evidenciar".

No reemplazar estas expresiones simplemente por sinónimos artificiales. La prioridad es escribir de manera natural.

## 9. Evitar contenido genérico

Cada párrafo debe aportar información relacionada directamente con el tema.

No agregar explicaciones genéricas únicamente para aumentar la extensión del trabajo.

No incluir:

* definiciones innecesarias;
* antecedentes que no aporten al tema;
* afirmaciones obvias;
* repeticiones;
* conclusiones que simplemente repitan lo anterior;
* información que no esté relacionada con el objetivo del trabajo.

La extensión debe depender de la cantidad de información necesaria, no de una cantidad arbitraria de palabras.

## 10. Coherencia y uniformidad

Mantener durante todo el documento:

* la misma terminología;
* el mismo nivel de formalidad;
* la misma persona gramatical;
* una estructura lógica;
* transiciones naturales;
* coherencia entre párrafos;
* consistencia en las citas y referencias.

No utilizar diferentes términos para un mismo concepto solo para evitar repeticiones.

## 11. No copiar ni realizar paráfrasis superficial

Cuando una idea provenga de una fuente, no limitarse a cambiar algunas palabras del texto original.

La información debe comprenderse y expresarse con una estructura propia, manteniendo el significado original y citando correctamente la fuente.

No presentar como conocimiento propio una idea específica tomada de una fuente.

## 12. Cantidad de citas

No existe una cantidad de citas que deba cumplirse artificialmente.

La cantidad debe depender de:

* la complejidad del tema;
* la cantidad de afirmaciones que requieren respaldo;
* la disponibilidad de fuentes pertinentes;
* el tipo de trabajo solicitado.

Es preferible utilizar menos fuentes pero directamente pertinentes que llenar el documento con referencias irrelevantes.

Cuando sea posible, combinar diferentes fuentes académicas de calidad para respaldar los principales argumentos, evitando repetir innecesariamente la misma referencia.

## 13. Prioridad de las fuentes

Priorizar, en este orden aproximado:

1. artículos científicos revisados por pares;
2. documentos oficiales de instituciones;
3. normas técnicas y documentos normativos;
4. libros académicos;
5. tesis y repositorios universitarios confiables;
6. organismos internacionales;
7. documentación técnica oficial.

Evitar blogs, páginas comerciales, contenido sin autoría y sitios de baja calidad cuando exista una fuente académica o institucional mejor.

## 14. No rellenar vacíos con información inventada

Si el usuario proporciona información incompleta, no completar los datos mediante suposiciones.

Si falta:

* año;
* autor;
* página;
* DOI;
* título;
* dato estadístico;
* resultado;
* fuente;

buscarlo y verificarlo si es posible. Si no puede verificarse, indicarlo.

## 15. Antes de entregar el trabajo

Realizar una revisión final:

* [ ] Se declaró la norma de citación.
* [ ] Se indicó el idioma del texto y de las fuentes.
* [ ] Se indicó el origen de las fuentes.
* [ ] No existen autores o referencias inventadas.
* [ ] Todas las referencias utilizadas existen.
* [ ] Las fuentes fueron verificadas.
* [ ] La bibliografía cumple el límite de antigüedad solicitado.
* [ ] Las excepciones de antigüedad están justificadas.
* [ ] Cada cita respalda directamente la afirmación correspondiente.
* [ ] Las citas están ubicadas correctamente.
* [ ] No existen citas de relleno.
* [ ] No se inventaron páginas, DOI ni URLs.
* [ ] No hay paráfrasis superficial de las fuentes.
* [ ] El texto evita contenido genérico.
* [ ] El lenguaje es natural y académico.
* [ ] Existe coherencia terminológica y estructural.
* [ ] Las referencias bibliográficas corresponden exactamente a las fuentes citadas.
* [ ] No se agregaron referencias que no fueron utilizadas en el texto.
* [ ] No se utilizaron expresiones repetitivas o fórmulas típicas de textos generados automáticamente.

## Principio fundamental

**La prioridad no es producir muchas páginas ni muchas citas. La prioridad es producir un texto académico sólido, específico, coherente, natural y verificable, donde cada afirmación importante pueda rastrearse hasta una fuente real y pertinente.**
